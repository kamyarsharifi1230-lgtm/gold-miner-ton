GOLD MINER — نسخه آزمایشی تلگرام

این بسته یک نمونه اولیه است، نه سرویس درآمد تضمینی و نه ماینر واقعی.
امتیازهای بازی توکن TON نیستند و ارزش نقدی ندارند.
درخواست برداشت فقط در دیتابیس ثبت می‌شود؛ هیچ تراکنش TON انجام نمی‌شود.

برای اجرا:
1) یک ربات از @BotFather بسازید.
2) توکن ربات را فقط در متغیر محیطی BOT_TOKEN روی هاست امن قرار دهید.
3) فایل static/index.html را روی یک هاست HTTPS منتشر کنید.
4) آدرس HTTPS آن را در WEBAPP_URL قرار دهید.
5) برنامه را با Python 3.11+ اجرا کنید: pip install -r requirements.txt && python app.py
6) در BotFather، منوی Mini App یا Web App را با همان آدرس HTTPS تنظیم کنید.

متغیرهای محیطی:
BOT_TOKEN = توکن ربات (هرگز در چت یا کد عمومی قرار ندهید)
WEBAPP_URL = آدرس HTTPS فایل Mini App
ADMIN_ID = شناسه عددی مدیر (در این نمونه اختیاری و استفاده‌نشده)
DB_PATH = مسیر دیتابیس (اختیاری)

محدودیت‌ها:
- نسخه آزمایشی است؛ امنیت و مقیاس‌پذیری آن قبل از استفاده عمومی باید بازبینی شود.
- رفرال ساده است و ضدتقلب کامل ندارد.
- درخواست برداشت نیازمند بررسی و پرداخت دستی توسط مدیر است.
- هرگز عبارت بازیابی/Seed Phrase یا کلید خصوصی کیف پول را از کاربر نخواهید.
- برای پرداخت واقعی باید کیف پول خزانه، موجودی کافی TON، کنترل تقلب، حداقل برداشت و ثبت تراکنش روی زنجیره اضافه شود.
